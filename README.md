### 🛠 Projects
**VIDEX: Surveillance Video Understanding** (Jul 2025 – Aug 2026)
- *Phase 1 · Semantic Video Indexing & Retrieval:* Built a VLM-based retrieval system that combines captions with grounded objects into segment-level semantic identifiers, with object tracking, temporal localization, and hallucination reduction.
- *Phase 2 · Agentic Video QA:* Designed a planner-based agentic QA framework that integrates detection, action recognition, and scene understanding to answer questions with supporting evidence and reasoning traces.

**Vision-Based Korean Sign Language Translation** (Jul 2024 – Dec 2024)
- Translated Korean sign language into natural language using hand and facial landmarks extracted with MediaPipe, exploring vision-based gesture and motion understanding.
